HKUDS/CLI-Anything

Python 63,571 stars LLM API optional
+783 stars today

A project that aims to make any software usable by AI agents through a command-line interface.

CLI-Anything from HKUDS tackles the agent-computer interaction problem by generating structured CLI harnesses for existing software so AI agents can operate them deterministically. A 7-phase pipeline (run from a coding agent) analyzes a codebase and produces a CLI with --json flags, self-describing --help text, an interactive REPL, and a SKILL.md that agents can read to discover capabilities. The growing CLI-Hub registry already covers over 40 tools including LibreOffice, Blender, ffmpeg, and game engines. It trends as developers realize GUI-scraping is brittle and want agents to call real APIs instead. Teams running automation workflows with Claude Code, Cursor, or Codex are the primary audience.
