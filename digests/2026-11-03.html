vercel-labs/agent-desktop

Rust 12,512 stars LLM API optional

A CLI that lets AI agents observe and operate desktop apps via accessibility trees.

agent-desktop gives AI agents a structured, reliable way to operate desktop applications — not through fragile screenshots, but via each platform's native accessibility tree (AX on macOS, UI Automation on Windows, AT-SPI on Linux). It outputs stable ref IDs agents act on, and stale refs return error codes rather than silent failures. A high-profile Vercel Labs release on computer-use tooling drove its surge to nearly 3,800 stars today. Developers building desktop automation agents or integrating AI into GUI-driven enterprise workflows are the primary audience.

A CLI for Git worktree management designed for parallel AI agent workflows.

worktrunk wraps Git's native worktree system in a developer-friendly CLI, letting you spin up and tear down isolated branches in seconds with a single `wt switch` command. Trending on organic interest from developers who run Claude Code or Codex concurrently and find raw `git worktree` commands cumbersome. Teams doing multi-agent parallelism on a monorepo will get the most value.

JustVugg/colibri

C 47,201 stars No LLM API needed
+803 stars today

A tiered inference engine for large MoE models: hot experts on GPU, warm in RAM, cold on NVMe.

colibri is a pure-C inference engine that makes frontier-scale mixture-of-experts models like DeepSeek V4 and Qwen3.6 runnable on ordinary consumer hardware by streaming expert weights from NVMe while pinning hot ones to the GPU and warm ones in RAM. The result is roughly equivalent to having far more VRAM than your machine actually has, at the cost of speed. It trended today on continued excitement around running frontier models locally without cloud API bills. ML researchers, local-AI enthusiasts, and developers who want an OpenAI-compatible local server for coding assistants are the core users.
