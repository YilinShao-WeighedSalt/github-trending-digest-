ag-ui-protocol/ag-ui

TypeScript 17,811 stars LLM API required
+393 stars today

A protocol for Agent-User Interaction that brings AI agents into frontend applications.

AG-UI defines a lightweight, event-based protocol for the layer between AI agents and user interfaces: agents emit typed events (streaming text, state mutations, tool calls, human-in-the-loop requests) and frontends render them in real time over SSE, WebSockets, or webhooks. It sits alongside MCP (agent-to-tool) and A2A (agent-to-agent) in the emerging "agent connectivity" stack. It is trending as developers standardize agent UX patterns and major frameworks — LangChain, CrewAI, Google ADK, and the Claude Agent SDK — have published native connectors. Frontend engineers and agent-platform teams building agent-powered interfaces across any stack are the target audience.
